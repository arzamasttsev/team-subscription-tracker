# Карточка продукта

| Поле | Значение |
|---|---|
| Номер | 226 |
| Название | Учёт подписок команды |
| Репозиторий | `team-subscription-tracker` |
| Профиль | приложение с сервером: FastAPI + SQLite + React, Docker Compose |
| Версия | 1.0.0 (шестая партия, 2026-11-22) |

## Аудитория и задача

Небольшая команда платит за десяток сервисов с ограниченным числом мест: дизайн, задачи, видеосвязь, хранилище. Учёт обычно живёт в таблице: кто сидит на каком месте, когда продление, сколько и в какой валюте. Таблица не мешает выдать шестое место при пяти оплаченных, освобождённое место пропадает из истории, а итог платежей складывает рубли с долларами. Операционному менеджеру нужно видеть свободные места, назначать их без превышения лимита и знать, что и когда придётся оплатить.

## Сценарий

1. Менеджер добавляет подписку: сервис, тариф, число мест, сумма за период и валюта, период оплаты, дата продления.
2. В карточке подписки назначает места сотрудникам. Когда мест нет, карточка говорит об этом вместо формы выбора, а запрос из устаревшей вкладки сервер отклоняет с актуальной занятостью.
3. Освобождает место: запись уходит в историю с автором и временем.
4. «Платежи» показывают продления в окне 7–90 дней с итогами отдельно по каждой валюте и просроченные даты, которые надо отметить. «Оплачено» сдвигает дату на период.
5. «Сводка»: всего мест, занято, свободно, подписки со свободными местами и без них, платежи за 30 дней, выгрузка CSV.

## Функции версии 1.0

- Подписки с тарифом, местами, суммой в минимальных единицах валюты (RUB, USD, EUR, CNY, KZT), периодом (месяц, квартал, год) и датой продления.
- Назначение и освобождение мест, история мест, журнал изменений подписки.
- Платежи по окну: каждая дата окна отдельно, итоги по валютам, просроченные даты, отметка оплаты со сдвигом на период от прежней даты.
- Правка подписки с проверкой версии, отмена подписки без занятых мест.
- Сотрудники: список с числом мест, карточка с подписками, добавление.
- CSV для таблиц с защитой от формул. Роли: операционный менеджер и администратор. Docker, том для базы, демо и синтетика.

## Практический результат

Из 7 одновременных запросов на последнее место проходит один, остальные получают «Свободных мест нет». На 1005 подписках и 2008 сотрудниках список подписок отвечает за 19 мс, платежи за 30 дней — за 8 мс, сводка — за 22 мс. Задержка ввода в поиске — 50 мс вместо 150–290 мс до оптимизации.

## Границы текущей версии

- Нет курсов валют и общего итога в одной валюте: итоги только по каждой валюте отдельно.
- Нет связи с биллингом сервисов: даты продления и суммы вводятся вручную, «Оплачено» отмечают руками.
- Нет уведомлений о близких продлениях.
- Сотрудников нельзя удалить или пометить уволенными через интерфейс.
- Один часовой пояс команды (`TZ_OFFSET_HOURS`). Один экземпляр сервера: SQLite не рассчитан на несколько реплик.
